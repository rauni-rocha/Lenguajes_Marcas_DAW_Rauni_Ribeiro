# Lenguajes de Marcas - 1º DAW

Este repositorio contiene mis ejercicios de Lenguajes de Marcas del primer trimestre.
La idea es practicar HTML y CSS, guardar los ejemplos de clase y tener todo mas ordenado.

## Organización

- `index.html`: página de entrada con los enlaces a cada tema.
- `miniweb/`: ejercicio de rutas relativas entre archivos y carpetas.
- `apuntes_tema_3_4/`: textos y pruebas simples de estilos que usamos al principio.
- `tarea_tema_3/`: encabezados, párrafos, imágenes y enlaces dentro de una página.
- `tarea_tema_4/`: listas ordenadas y no ordenadas, enlaces, imágenes e iframe.
- `tarea_tema_5/`: tablas, combinaciones de celdas y varios formularios.
- `tarea_tema_6/`: etiquetas semánticas de HTML con ejemplos de animales de Brasil.
- `tarea_tema_8/`: propiedades de CSS (bordes, modelo de caja, overflow, display, fuentes y menú).
- `tarea_tema_9/`: 15 ejercicios para practicar Flexbox.

## Para qué sirve

Lo uso para repasar las cosas que hemos visto en clase: como organizar una web,
crear enlaces entre páginas, hacer tablas y formularios y cambiar el diseño usando CSS.
Cada tema tiene sus archivos y es más fácil encontrar un ejercicio cuando lo necesito.

## Cómo abrirlo

Se abre `index.html` con el navegador, y desde esa página se puede ir a los temas.
Los ejercicios son HTML y CSS basicos. Los formularios mandan datos a `procesar.php`,
y para que ese archivo funcione hace falta un servidor con PHP. Si abro los HTML
como archivos locales, el PHP no se ejecuta.
