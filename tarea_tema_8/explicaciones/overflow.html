Cuando un texto es muy grande para una caja, overflow decide lo que pasa.

visible

Estoy escribiendo un texto largo dentro de una caja pequeña para mirar como desborda, y ver que no se corta.

hidden

Estoy escribiendo un texto largo dentro de una caja pequeña para mirar como desborda, pero lo que sobra se oculta.

scroll

Estoy escribiendo un texto largo dentro de una caja pequeña y ahora hay barras para poder mover el contenido de esta caja.

auto

Estoy escribiendo un texto largo dentro de una caja pequeña. El navegador puede enseñar la barra si necesita.
